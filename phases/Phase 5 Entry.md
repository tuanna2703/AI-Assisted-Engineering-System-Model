## 5. Entry Constraints

Phase 5 shall observe the following constraints:

### 5.1 Architectural preservation

The following distinctions remain frozen:

```text
EPM ≠ PEM
Runtime ≠ Agent
Execution Context ≠ conversational memory
Engineering Decision ≠ Execution Determination
Engineering completion ≠ Runtime termination
Observation ≠ mutation
Agent capability ≠ authority
Contract ≠ protocol
Semantic interaction ≠ implementation
```

### 5.2 Implementation independence

Phase 5 shall remain implementation-independent unless an explicitly approved phase scope states otherwise.

### 5.3 Authority preservation

No Phase 5 artifact may grant authority to an Agent merely because the Agent can propose, observe, execute, verify, or technically perform an action.

### 5.4 Frozen-baseline preservation

A downstream issue shall not be resolved by silently editing a frozen upstream artifact.

### 5.5 Traceability

Material Phase 5 decisions, revisions, evidence, and validation results shall remain traceable.
